# A Hallway, But...

[![Play on Itch.io](https://img.shields.io/badge/Itch.io-Play%20Now-orange?style=for-the-badge&logo=itch.io)](https://redd855.itch.io/a-hallway-but)
[![Unity](https://img.shields.io/badge/Unity-2022.3LTS-black?style=for-the-badge&logo=unity)](https://unity.com/)

You are the only applicant accepted into the Long-term Observation of Ongoing Plasticity (L.O.O.P) program. Can you adapt to each change? Can you escape the hallway? Can you... wait, is that a duck?

Created in collaboration with [Reddyboi85](https://github.com/Reddyboi85) for the **GTMK 2025 Game Jam**!

## Controls
WASD / Arrow Keys -- Movement<br>
Space -- Jump<br>
Left-click -- Close Adblocker...?<br>
I -- Triggers the most incredible, most sophisticated idle animation you've ever seen in the last 50 years of gaming!<br>

## Tech Stack
**Engine:** Unity (C#)<br>
**Art:** Asesprite<br>
**Audio:** FL Studio & Audacity<br>
